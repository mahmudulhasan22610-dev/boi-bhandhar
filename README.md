# বই ভান্ডার - অনলাইন বই বিপণী 📚

একটি সম্পূর্ণ ই-কমার্স ওয়েবসাইট যা বই বিক্রয়ের জন্য ডিজাইন করা হয়েছে। এতে রয়েছে ব্যবহারকারী রেজিস্ট্রেশন, বই ক্যাটালগ, কার্ট সিস্টেম, অর্ডার ম্যানেজমেন্ট, পেমেন্ট প্রসেসিং এবং রিভিউ সিস্টেম।

## প্রযুক্তি স্ট্যাক 🛠️

### ব্যাকএন্ড
- **Node.js** - জাভাস্ক্রিপ্ট রানটাইম
- **Express.js** - ওয়েব ফ্রেমওয়ার্ক
- **MySQL** - রিলেশনাল ডাটাবেস
- **JWT** - অথেন্টিকেশনের জন্য
- **bcryptjs** - পাসওয়ার্ড এনক্রিপশন

### ফ্রন্টএন্ড
- **React** - ইউজার ইন্টারফেস
- **Axios** - API কল
- **React Router** - নেভিগেশন

## ইনস্টলেশন ⚡

### স্টেপ ১: ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### স্টেপ ২: ডাটাবেস সেটআপ করুন
```bash
mysql -u root -p < database/schema.sql
```

### স্টেপ ৩: পরিবেশ ভেরিয়েবল কনফিগার করুন
```bash
cp .env.example .env
```

### স্টেপ ৪: সার্ভার চালু করুন
```bash
npm start          # প্রোডাকশন
npm run dev        # ডেভেলপমেন্ট
```

সার্ভার `http://localhost:5000` এ চলবে।

## API এন্ডপয়েন্ট 📡

### অথেন্টিকেশন
- `POST /api/auth/register` - রেজিস্ট্রেশন
- `POST /api/auth/login` - লগইন

### বই
- `GET /api/books` - সকল বই
- `GET /api/books/:id` - নির্দিষ্ট বই
- `GET /api/books/search/:query` - সার্চ
- `GET /api/books/category/:category` - ক্যাটেগরি অনুযায়ী

### অর্ডার
- `POST /api/orders` - নতুন অর্ডার
- `GET /api/orders/user/:user_id` - ব্যবহারকারীর অর্ডার
- `GET /api/orders/:id` - অর্ডার বিস্তারিত

### রিভিউ
- `POST /api/reviews` - রিভিউ যোগ
- `GET /api/reviews/book/:book_id` - বইয়ের রিভিউ
